# 003-security-group: セキュリティグループを追加し80番を許可する

## 背景・目的

`002-ec2-only` で起動したEC2インスタンスに、初めてセキュリティグループを追加する。このお題で新しく学ぶ概念は「セキュリティグループ」1つだけに絞る。HTTPサーバーはまだ立てない（次のお題 `004-user-data-nginx` で扱う）。ゴールは、80番ポートのみを許可するセキュリティグループを作成し、EC2インスタンスに紐付けることである。

`002-ec2-only` の `terraform/` の中身をコピーし、その上に `aws_security_group` リソースを1つ追加する形で進めること。

## 登場する概念（詰まったら調べる）

- **セキュリティグループ**: EC2インスタンスに対する仮想的なファイアウォール。「どのポートへの、どこからの通信を許可するか」をルールとして設定する。EC2インスタンスとセキュリティグループは別々のリソースとして作成し、EC2インスタンス側から「このセキュリティグループを使う」と参照する形で紐付ける。
- **インバウンドルール / アウトバウンドルール**: セキュリティグループの中に定義する、それぞれ「入ってくる通信」「出ていく通信」の許可設定。今回はインバウンドの80番（HTTP）のみを許可する。

## 進め方の手がかり

1. `002-ec2-only/terraform/` の中身を `003-security-group/terraform/` にコピーする
2. `aws_security_group` リソースを追加し、インバウンドで80番のみを許可するルールを書く
3. EC2インスタンス側の設定を変更し、作成したセキュリティグループを参照するようにする（デフォルトセキュリティグループから切り替える）
4. `terraform plan` で意図通りの差分（セキュリティグループの新規作成、EC2インスタンスの更新）になっているか確認する
5. `terraform apply` し、`aws ec2 describe-security-groups` でルールを確認する

## 要件（Must）

- [ ] EC2インスタンスを1台起動し、`running` 状態であること（`002-ec2-only` の内容を引き継ぐ）
- [ ] セキュリティグループを1つ作成し、EC2インスタンスに紐付けること
- [ ] セキュリティグループのインバウンドルールがTCP 80番（HTTP）の許可を含み、かつ80番以外のポートを一つも開放していないこと（SSH/22番も含む）

## 制約（禁止事項）

- インバウンドルールに80番以外のポートを追加しないこと
- 使用可能なAWSサービスはEC2（デフォルトVPCの利用を含む）・セキュリティグループに限定する
- `user_data` は設定しないこと（`004-user-data-nginx` で扱う）

## 推奨（Should）

- リソース名には `dojo-shiro-` などのプレフィックスを付ける
- `Name` タグを付けておく（例: `Name = "dojo-shiro-sg"`）。まだ `terraform output` を使わないため、テスト実行時にタグやセキュリティグループ名で検索すると探しやすい
- セキュリティグループのルールには `description` を設定し、許可理由を明記する

## 受入テスト

`tests/acceptance.sh` を参照。概要は以下の通り。`terraform output` は未定義のため、`terraform apply` 後に自分でインスタンスID・セキュリティグループIDを確認し、環境変数として渡して実行する。

| # | 検証内容 | コマンド例 | 期待結果 |
|---|---|---|---|
| 1 | セキュリティグループのインバウンドルールが80番のみを許可している | `aws ec2 describe-security-groups` | 80番の許可ルールが1件以上、かつ80番以外の許可ルールが0件 |
| 2 | インスタンスが `running` 状態であり、セキュリティグループが紐付いている | `aws ec2 describe-instances` | `State.Name` = `running` かつ `SecurityGroups` に対象のSG IDが含まれる |

## スコープ外

- HTTPサーバーの起動（`004-user-data-nginx` で扱う）
- `terraform output`（`005-outputs` で扱う）
- 送信元IPを絞り込む設計（踏み台経由アクセスなど。黄帯以降で扱う）
- ALB・Auto Scaling Group・複数AZ構成（黄帯で扱う）
